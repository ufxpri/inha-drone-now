# 코드 지도 (한눈에 보는 구조)

이 프로젝트의 핵심은 딱 한 문장이다:
**"지도를 클릭하면 → 5곳에서 데이터를 모아 → 판정하고 → 화면을 채운다."**

---

## 1. 전체 흐름

```
                         ┌─────────────────────────────────────────┐
   사용자가 지도 클릭  ──▶ │  DashboardController.onMapClicked(위치)   │  ← 모든 일의 시작점
                         └───────────────────┬─────────────────────┘
                                             │ (백그라운드 SwingWorker)
            ┌────────────────────────────────┼────────────────────────────────┐
            ▼                ▼                ▼               ▼                 ▼
     ┌────────────┐  ┌──────────────┐  ┌───────────┐  ┌────────────┐  ┌──────────────┐
     │WeatherClient│ │RainForecast  │  │NotamClient│  │SunTimeClient│ │NoFlyZoneStore│
     │ 풍속·기온   │  │ 강수확률예보 │  │ 항공경보  │  │ 일출·일몰  │  │ 공역(로컬)   │
     └─────┬──────┘  └──────┬───────┘  └─────┬─────┘  └─────┬──────┘  └──────┬───────┘
           └────────────────┴────────┬───────┴──────────────┴────────────────┘
                                      ▼
                        ┌───────────────────────────┐
                        │   FlightSafetyJudge.judge  │  6개 항목 검사
                        │  풍속·강수·NOTAM·공역·주간·자격│  하나라도 NO_GO → NO_GO
                        └─────────────┬─────────────┘  CAUTION 있으면 → CAUTION
                                      ▼
            ┌──────────────┬──────────┴───────┬───────────────┐
            ▼              ▼                  ▼               ▼
     ChecklistPanel  ConditionsPanel    NotamPanel    NoFlyZonePanel   ← 화면 갱신
     (GO/CAUTION/    (게이지·나침반     (목록·필터)    (목록)
      NO-GO 배너)     ·타임라인)
```

---

## 2. 패키지 = 역할별 서랍

| 서랍 | 무슨 일을 하나 | 대표 파일 |
|------|---------------|----------|
| `api` | 바깥 데이터 가져오기 | `*Client` (공통 부모 `CachedApiClient`) |
| `io` | 파일·캐시·공역 읽기 | `FileCacheStore`, `NoFlyZoneStore` |
| `judge` | 비행 가부 판정 | `FlightSafetyJudge` |
| `controller` | 위 셋을 엮어 흐름 지휘 | `DashboardController` |
| `view` | 화면 그리기 | `MainFrame` + 각 Panel |
| `model` | 데이터 그릇 (record/enum) | `Location`, `dto/*Info` |

---

## 3. 새 코드를 읽을 때 추천 순서

1. **`DashboardController.onMapClicked`** — 전체 흐름의 뼈대. 여기만 읽어도 80%를 안다.
2. **`FlightSafetyJudge`** — GO/CAUTION/NO_GO가 결정되는 규칙.
3. **`CachedApiClient`** — 모든 API 클라이언트의 공통 동작(캐시 → 없으면 호출).
4. 그다음 필요한 개별 `*Client` / `*Panel`만 골라 읽으면 된다.

---

## 4. 판정 규칙 요약 (FlightSafetyJudge)

| 항목 | NO_GO 조건 | CAUTION 조건 |
|------|-----------|-------------|
| 바람 | 풍속 > 12 m/s | 풍속 > 8 m/s |
| 강수 | 강수량 > 0 mm | 정보 없음 |
| NOTAM | 금지/제한 구역 내부 | 경고 구역 내부 / 주변 10km |
| 공역 | 비행금지 폴리곤 교차 | 정보 없음 |
| 주간 비행 | 일출 전·일몰 후(야간) | 정보 없음 |
| 자격 | (없음) | 자격 미보유 |

→ 6개 중 **하나라도 NO_GO면 NO_GO**, 아니면 **CAUTION 하나라도 있으면 CAUTION**, 다 통과면 GO.
